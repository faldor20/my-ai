# Bladebro Browser

Use the bladebro tools for all browser interaction.

- act: act on the page
- see: observe without acting
- run: act with branching/loops
- state: tabs, cookies, sessions
- vision: screenshot, last resort for interaction, good for debugging layout or graphics
