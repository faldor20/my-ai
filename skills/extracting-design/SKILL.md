---
name: extracting-design
description: How to take a website design/template and extract all the info we need to define a theme/design system for that site
---

You are going to take some premade website or template, probably a single html file and you are going to read through and extract the key design choices.
radiuses
shadows
colours (including variants of the same colour eg hover muted etc)
text sizes (heading and body) and fonts

you will then lay all this out in a super clear html document. keep colour variants together with what you think is the base colour, show different variants of headings grouped by their heading size, same with body text, show all the fonts and what they are used in, bold small large etc

We will use this to make themes and base styling for the final implementation.

ensure everything is clearly labeled if something has a particular use note that in smaller detail text
